## Grounding of predeclared expectations

**q1: consequential contract violation is supported.** `cases/q1/README.md:14-19` explicitly makes replacement of CURRENT the commit point, says complete bytes and checksum do not constitute commitment, and requires reopening to preserve the initial empty state. `artifacts.py:61-65` writes a complete generation before replacing the pointer (`:37-40`). After replacement fails on an initially empty store, `read()` returns None (`:69-71`), but reopening calls `recover()` (`:13`), which promotes the newest complete generation when CURRENT is absent (`:42-49`). This exposes bytes from an operation that never reached its declared commit point. The manifest accurately confines this to the no-CURRENT boundary: an existing CURRENT makes recovery return early (`:45-46`). Diagnostic generation retention is expressly permitted (`README.md:11-12,21-24`) and is not a second defect. The public failure test begins by publishing an approved value (`test_artifacts.py:19-27`), so it genuinely misses first-publication interruption. A small fix preserving absent CURRENT as empty, plus that boundary test, is consistent with this contract; separate durable commit evidence is another possible design, not an existing requirement.

**q2: the intended false lead is legitimately excluded.** `cases/q2/README.md:8-12,17-20` explicitly retains keys and completed results for the entire bounded batch. `leases.py:15-19` returns the existing identity without requeueing and rejects a different payload; `:63` stores completion. New keys obtain new jobs (`:20-30`). Retention is not an unbounded-lifetime leak under `README.md:3-6`. Lease expiration uses deadline equality (`leases.py:36-38,57-60`); each reservation increments a queue-wide token (`:41-46`), and finish checks both token and expiry before mutation (`:55-64`). Therefore a reused owner name cannot authorize an old lease. Payload/result/snapshot copying supports the ordinary copyable-value contract (`:23,51,63,68-72`), and the public tests explicitly cover these paths. A scoped no-finding report is justified; persistence and cross-process locking would exceed the contract.

**q3: the declared clean scoped behavior is supported.** `cases/q3/changes.py:45-46` freezes upper revision at begin; `:48-49,54-66` preserves that upper bound and pages ordered retained events. Writes append new revisions (`:30-35`), so between-page writes remain available for a subsequent pull after the frozen checkpoint. Persisting the displayed checkpoint only after the last page is an explicit caller obligation (`README.md:9-15`), not a silent loss mechanism. Compaction retains only events beyond its inclusive floor (`changes.py:68-72`); positions strictly below the floor raise `CursorExpired` (`:56-57`), while equality stays valid. Expiration of active pulls is explicitly allowed (`README.md:17-23`). Deep copies at append and page construction protect normal dictionary values (`changes.py:34,66`). Snapshot endpoint, persistence, multiple writers, and hostile token transport are expressly elsewhere. No additional consequential defect was established within those boundaries.

## Novel conditional observation and uncertainty

`q2/leases.py:33-34` rejects `ttl <= 0` but does not reject NaN. By Python floating-point comparison rules, a NaN TTL passes this guard, produces a NaN deadline (`:46`), and makes both expiration comparisons false (`:37,60`). Such a lease cannot be reclaimed on time and can be completed arbitrarily later with its current token. This is a source-derived conditional validation concern, not an executed witness and not an unqualified consequential finding: the contract specifies monotonic supplied timestamps but leaves the accepted TTL numeric domain implicit. If the adapter guarantees finite positive durations, it is outside that valid-input domain; if this API itself promises to reject all nonpositive/nonfinite durations, validation needs tightening. Do not require auditors to invent an adversarial duration requirement, and do not reject a carefully qualified observation solely because it is absent from the oracle.

No other consequential novel defect was established. Small synthetic sources and seven targeted checks leave ordinary uncertainty about unexercised inputs and integrations; that uncertainty should not be converted into asserted findings.
