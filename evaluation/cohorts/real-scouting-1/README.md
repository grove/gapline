supplied UTF-8 text file. Each `rN.tar.gz` contains those unchanged files,
including upstream licenses/notices. Binary exclusions are explicit. The
archives are evaluation inputs, outside the installable Gapline payload.

budget, order and independent judgments. Reconstruct with the evaluator's
`run_real_scouting.supply`, which validates the archive and exact byte identities;
never execute repository content during audits.

`skills/B` restores only the Scout paragraph and optional scouting recipe from
PR #11. Both retain the current shortened verification wording from #7.

trees. Workers must never receive this README, manifest, protocol, expectations,
archive names, other methods, prior reports or evaluator records. Once published,
these inputs are seen examples, unsuitable for another claimed fresh trial.
